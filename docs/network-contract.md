# Trusted request and browser boundary

Independent test specification. Read no implementation.

`packages/adapters/src/network.ts` exports `publicAddress(address)` and `TargetTransport`. publicAddress rejects non-IP strings, IPv4 private, loopback, unspecified, link-local, carrier-grade NAT, multicast, reserved/documentation/benchmark ranges. IPv6 support must not allow loopback/link-local/unique-local/mapped private addresses. Conservative rejection is acceptable; an accepted public address does not authorize a target by itself.

`new TargetTransport({origin,allowLoopback,timeoutMs?})`. origin must contain no userinfo/query/fragment/path except '/'. HTTPS is required unless the operator explicitly allows exact 127.0.0.1 HTTP. 'localhost' is not interchangeable with the fixed address. `request(path,{method?,headers?,body?,beforeDispatch?}?)` only accepts an absolute same-origin path beginning '/' but not '//', no backslashes. Before connecting, resolve and reject forbidden IPs, pin the checked destination for the actual connection, call optional beforeDispatch synchronously after DNS and immediately before dispatch. Do not follow ANY redirect. Reject responses over1MiB and overall deadline, not merely idle timeout. Return `{status,body,rawBody,headers}` where body is parsed JSON or the actual text, not an invented placeholder. beforeDispatch throws => zero target requests. No cookies/credentials should be forwarded to a redirect destination.

`packages/adapters/src/browser.ts` exports `BrowserRunner`. Construct with `(transport,artifactDirectory)`; call `probe(cookie)` using ordinary disposable user cookie only. Browser starts /dashboard, clicks data-testid export-button, waits for export-result data-status and visible result. A valid visible allowed state is data-status='allowed' with exact marker in nested pre; network response must have matching fixtureMarker. A valid denied state is data-status='denied' with visible denial and network denial contract. Return `{probe:{status,body,transportError,denialStatuses},artifact}`. No body marker from the actual network response may be discarded just because UI says denied. Rendering a marker without matching successful network evidence is not a trustworthy allowance. UI allowed and network deny, or UI denied and malformed network contract, cannot pass pure evaluateProbe.

All browser traffic is restricted to configured origin and GET /dashboard, /api/me, /api/export or /_next/* assets. Redirects must be blocked before following, even a permitted endpoint redirecting to another loopback port. Websocket and service-worker bypasses are disabled. No request to cloud metadata, external pages or provider APIs is authorized. Use temporary local HTTP servers for contract faults and actual browser; clearly label fixtures synthetic and don't count them as a real reference-app/Stripe run. Close servers/browser and remove only each test's own temporary files.

Representation clarification: `rawBody` is a Uint8Array (a Node Buffer is valid), preserving the exact response bytes, including binary Next.js assets. Text fixtures may decode those bytes as UTF-8 when comparing their content. The parsed `body` remains JSON or actual text. A browser transport failure returns an explicit error probe with `transportError: true`, `status: null`, and `artifact: null` when no image was collected; it must not invent an HTTP response or screenshot. This is inconclusive under the additive transport-failure variant in public-contracts.md.
